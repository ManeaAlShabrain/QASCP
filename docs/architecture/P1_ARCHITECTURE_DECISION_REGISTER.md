## Candidate conflict/denial examples for review

| Input | Proposed disposition / acceptance trace |
|---|---|
| Two sources disagree on asset criticality and no adopted field rule exists | Preserve both attributable claims; canonical conclusion unresolved. No timestamp/name-based overwrite. |
| Connector A supplies connector B's identifier or evidence | Deny generically under current binding; no resource existence disclosure. BA02/06. |
| Same display/source ID in tenants A and B | Distinct registry/binding/claims; no merge or cross-tenant lookup. BA02. |
| Same command key across resource and relationship families, different bytes | 409 digest conflict with no second domain effect. BA04/08. |
| Existing source_id arrives for a different resource | Ordinary import conflicts/quarantines; separate attributed resolution required. BA06. |
| Same event processed by a second replica | Existing logical receipt; distinct event at same schema version processes separately. BA04. |
| Revoked privilege, stale expected_version, expired snapshot | Deny/restart before payload/effect; no fabricated success, counts or completion. BA06/07/08. |
