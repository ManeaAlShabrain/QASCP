## الموقف العربي

يحدد السجل استعمال كل مرجع من المراجع الخمسة عشر ضمن البحث والبيانات الوصفية
والروابط فقط، مع إبقاء النصوص الدقيقة والحقوق والانطباق والنشر التجاري محجوبة
حتى مراجعتها. لم تُسترجع مصادر جديدة هنا ولا يُدعى أنها حديثة أو مكتملة.
التصميم مستقل؛ ولا تعني مصفوفة القدرات تحقق بنود تنظيمية أو شهادة امتثال.

رُوجعت بيانات تراخيص اعتماديات التحقق التسعة عشر المحفوظة ضمن نطاقها السابق،
لا كنصوص ترخيص كاملة أو فحص أمني شامل. المقترح استمرار التحقق الداخلي المثبت
بالبصمات دون حزم الاعتماديات أو إعادة توزيعها كإصدار QASCP. تتطلب أي خطوة
توزيع أو تعديل أو نشر مراجعة النصوص والإشعارات والحقوق والحزمة الدقيقة، ولا
تُقبل حقوق طرف آخر بقرار مالك المشروع. تبقى المراجعة المنفصلة واعتماد النطاق
الداخلي للمالك مطلوبين؛ لا تُختلق موافقة تنظيمية أو قانونية.
